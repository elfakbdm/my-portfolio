About

I write the code most marketers only click a button for.

I'm an AI engineer working in digital marketing — not a marketer who occasionally uses AI tools. The difference shows up in what I actually build: Python pipelines, API integrations, and full applications, not just prompts typed into a chat window.

Every project in my portfolio is real, running code — an AI marketing analytics tool built with Pandas and the OpenAI API, a Streamlit + FastAPI SEO auditor, an agentic-automation pipeline, and AI-generated campaign visuals and video. These aren't case studies run through someone else's SaaS product; they're software I designed and shipped myself.

That engineering background changes how I approach marketing problems. Instead of "the campaign underperformed," I trace it to the specific data point. Instead of running a report manually every week, I automate the pipeline. Instead of one AI prompt, I build a system of chained prompts and templates that reliably produces on-brand output at scale.

I'm continuously adding new projects — you can follow the full, growing list on the Portfolio page.
